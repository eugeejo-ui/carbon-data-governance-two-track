# carbon-data-governance-two-track

탄소 데이터 거버넌스 투트랙 판매 계획 (제조: CBAM 대응 + 은행 심사 연계 / 금융: 금융배출량)

- 무엇을 파나: 탄소 숫자의 출처·실측 여부·변경 이력을 증명하는 층 (IBM watsonx.data intelligence)
- 제조 트랙: CBAM 대상 제조사. CBAM 신고와 은행 서류·대출 심사에 함께 쓰는, 출처가 증명되는 탄소 데이터로 제안함
- 금융 트랙: 금융배출량 공시 대상 금융사. 차주 배출 데이터를 실측·추정·출처로 구분해 관리하도록 제안함
- 두 트랙은 따로 진행하며 우열·순서를 비교하지 않음
- 현재 단계: 준비 완료, 제조-1(명단 확정) 착수 전
