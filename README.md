### 프로젝트 성격

- 통계 자료에서 새로운 인사이트를 발견·도출하는 탐색형 분석이 아님
- 확정된 규제 일정과 공개 자료를 기준으로, 최적의 접촉 시기와 규모를 갖춘 기업을 선별하는 작업임
- 따라서 판단의 무게는 데이터의 양이 아닌 선별 기준의 타당성과 근거의 추적 가능성에 있음

### 본 발표가 답하는 질문

- 누구에게: 탄소 데이터 거버넌스 제품(IBM watsonx.data intelligence)을 어떤 규모의 어느 제조사·금융회사에 제안하는가
- 언제: 각 기업에 어느 연도에 접촉하는가

### 발표 범위

- 본 레포(carbon-data-governance-two-track)의 진행 문서 00~07을 범위로 함
- 시연 단계(진행 문서 08~10)는 본 발표 범위에서 제외함

<summary><b>탭 1. 출발점 — 은행 수출서류 판독 시스템의 한 층</b></summary>

### 1-1. 출발 배경

- IBM의 전통적 강점은 금융 고객 기반임
- 따라서 첫 선행 프로젝트(trade-doc-parsing-model-eval)는 은행의 수출서류(신용장 부속서류) 판독 업무에서 시작함
- 선행 프로젝트 결과: 은행 내부 서버에 설치 가능한 판독 모델 2종(IBM Granite Docling 258M · PaddleOCR-VL 0.9B)의 상업송장 150장 금액·날짜·상호 추출 정확도가 동일함. 도입 여부는 모델 성능이 아닌 운영비와 재제출 비용의 비율이 결정함

### 1-2. 은행 판독 시스템에 모델 한 층으로 진입하는 근거

- 출처: 딜로이트 「아시아태평양 금융서비스 산업의 미래」(2026-09)
  - 공급망 재편으로 무역금융·거래은행 수요가 증가함 (13쪽). 한국에도 무역금융 수요가 존재함 (18쪽)
  - 선택적 내재화: 판단 규칙·판단근거 기록은 은행이 보유하고 범용 모델은 외부에서 도입함. 한국은 망분리·데이터 민감도·규제 승인 부담이 내재화 범위를 결정함 (36쪽)
  - 기술주권: 금융회사 80%(아시아태평양 87%)가 AI 공급사 선정 시 출신 국가를 고려함. 보고서는 완전한 독립이 아닌 신뢰할 수 있는 파트너십을 권고함 (39쪽)
  - 실제 사례: KB국민은행의 법인 고객 확인 서류 AI 판독 (42쪽)

### 1-4. 국내 대형·중견 금융사의 판독 AI 자체 구축 현황

**조사 대상과 규모 구분**

- 대상: 신용장·수출환어음 업무를 취급하는 국내 은행 17곳과 인터넷은행 3곳, 비은행 대형 금융사 26곳
- 대형 은행: 금융위원회 지정 시스템적 중요 은행 5곳(국민·신한·하나·우리·농협, 2027년도 지정)과 지정 기준을 넘었으나 국책은행이라 제외된 2곳(산업·기업)
- 중견 은행: 그 외 시중·특수·지방은행 10곳
- 확인 방법: 회사 공식 발표·주요 언론·감독기관 자료로 확인함. 공개 자료가 없는 경우는 '공개 자료 없음'으로 표시하며, 미도입을 의미하지 않음

**참고 통계**

- 국내 금융권의 AI 자체 개발·외부 조달 비율에 대한 공식 통계는 확인되지 않음 — 금융감독원 전수조사(2025-04, 118개사, AI 서비스 653개)는 구분 수치를 공개하지 않음
- 핀테크산업협회 포럼 발표(2026-06-23): AI 도입 금융사 중 자체 모델 개발 10% — 표본·조사 주체 비공개로 참고 수치에 해당함
- 국내 금융회사 IT 인력의 51.7%가 외부 인력임 (한국은행 금융정보화추진협의회, 2023년 말, 145개사)
- 글로벌 금융업계의 63%가 외부 기반 모델 위에 내부 업무 흐름을 구성함 (케임브리지 대안금융센터, 2026, 628개 기관)

**해석**

- 판독 AI 자체 개발은 그룹 IT 조직을 보유한 일부 대형 금융그룹(하나·KB)과 국책은행(기업은행)에 한정됨
- 대형 은행 7곳 중 5곳은 판독 AI를 운영하거나 구축 중임 → 선행 프로젝트가 범위 밖으로 둔 '솔루션 교체' 영역에 해당함
- 진입 여지는 국내 도입 공개 사례가 없는 중견 은행 10곳과 공개 자료가 없는 대형 은행 2곳(농협·산업)에 남음
- 공개 자료 부재는 미도입을 의미하지 않으므로, 진입 여지는 좁고 공개 자료만으로 즉시 식별되지 않음 → 공개 자료와 규제 일정으로 대상과 시점을 체계적으로 선별하는 방법이 필요함

**불리한 근거**

- 신한은행은 외부 상용 모델(OpenAI GPT)을 혁신금융서비스 지정과 금융보안원 보안평가를 거쳐 수출서류 심사에 적용함 → 은행 내부 배포 전제와 다른 사례임
- 우리은행은 국내 SI(삼성SDS)를, 지방은행은 국내 클라우드 사업자(네이버클라우드·KT)를 선택하는 흐름임 → 모델 층 공급은 SI 경유 가능성이 큼
- KB AI-OCR은 부수업무 지정으로 외부 판매가 가능하며 하나금융 리딧은 그룹 외부(포스코인터내셔널)에 판매됨 → 금융그룹 IT 조직도 공급자로 경쟁함
- 비은행 대형 보험사 다수는 국내 문서 AI 업체 솔루션을 운영 중임 → 자체 미구축 금융사 상당수는 빈 시장이 아닌 교체·고도화 시장임
- IBM은 SC그룹과 무역서류 AI를 공동 개발한 이력(2019)이 있으나, 모델 한 층이 아닌 공동 완성 솔루션 형태였음

### 1-5. 결론과 남은 질문

- 결론: IBM은 완성 시스템이 아닌 판독 모델 한 층으로 진입하며, 매출은 그 층에 붙는 면책·기술 지원·플랫폼 계약에서 발생함
- 하나은행 사례의 성격: 규모 있는 은행이 판독 시스템을 내부 서버에 직접 구축한다는 실제 사례이며, IBM 납품 근거는 없음
- 남은 질문: 판독 AI를 자체 구축하지 않은 금융사를 공개 자료로 어떻게 찾고, 어느 시점에 접근하는가
- 선행 프로젝트(trade-doc)는 '무엇을 제안하는가'를 결정했으나 '누구에게·언제'는 다루지 않음 → 탭 2의 과정을 거쳐 본 레포가 이 질문을 이어받음
