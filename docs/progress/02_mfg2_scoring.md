- 합계 만점 **10점**. 동점 처리: ② → ⑥ → ④
- 3등분: 자료 있는 n곳을 값이 큰 순서로 정렬해 앞 ⌈n/3⌉곳 2점, 다음 ⌈n/3⌉곳 1점, 나머지 0점. 경계에 같은 값이 걸리면 높은 점수로 묶음
- 자료 없으면 0점. 예외: ⑤는 "없음" 자체가 답이라 2점
- ⑥은 순위 정렬에만 쓰고 가설 판정에는 쓰지 않음 (H1·H2는 ②④⑤로만)

## 4. 운영 규칙

### 4-1. ② 정부 검증 총량

- 배출권 할당대상 여부를 먼저 보고, "아님"인 계정은 산업통상부 온실가스 목표관리업체 지정고시와 대조함
- 전체 명단은 5년 계획기간 단위 고시(2025-100호)에 있고 이후 고시는 변동분만 담으므로 둘을 합쳐 봄
- 적용기준 제1호는 업체(5만 tCO2e), 제2호는 사업장(1.5만 tCO2e)
- 지정취소된 계정은 1점으로 두고 "이전 관리업체"로 표시함
- 기록: data/manual/mfg2_kets_managed.csv

### 4-2. ③ 공장 매칭

- 순서: 이름 정리 → 정확 일치 → 동명 회사 소재지 구분 → 같은 주소 중복 제거 → 공장 수·시도 수 → 점수
- 동명 회사 구분, 매칭 0곳은 "확인 필요"로 두고 사람이 판단함
- 기록: data/manual/factory_match_review.csv

### 4-3. ④ IT 예산

- 값: 정보보호 공시의 "정보기술부문 투자액(A)". 2026 공시를 먼저 쓰고 없으면 2025 공시를 씀
- 3등분 집단: 중견 / 대기업(대기업·대기업 계열·외국계)을 따로 나눔
- 공시 대상이 아니어서 값이 없는 계정은 0점과 "④ 자료 없음" 표시 (예산이 작다는 뜻이 아님)

### 4-4. ⑤ 2층 경쟁 상태

- ⑤가 재는 것은 **2층(거버넌스) 경쟁**임. 3층(산정·LCA·PCF·EPD)이나 1층(수집)만 갖춘 것은 2층 경쟁이 아님
- 계정마다 competitor_layer 칸에 상대의 층을 적음 (1층/2층/1~2층/1~3층/1~4층/3층/설비/기준 G/없음)
- 기준 D를 D-1(출처·검증 관리 시스템 자체 구축, 0점)·D-2(산정 솔루션·LCA·EPD만, 2점)·D-3(수집·통합 시스템만, A안에서 2점)로 나눔
- 증거 강도 배점: 원문+보도 0점 / 하나만 1점 / 둘 다 없음 2점. **경쟁 층이 2층·1~2층인 계정에만 적용**하고 3층·설비 계정은 2점 유지
- evidence_source 칸에 원문+보도 / 보도만 / 원문만 / 추정 / 없음을 적음
- 조사 순서: mfg2_base의 우리 자료 → DART 원문 용어 스캔 → 웹 개별검색. 묶음 검색은 표시하고 개별 재검색 대상으로 남김
- 기록: data/manual/mfg_competition_evidence.csv (판정마다 출처 URL·발행일·확인일·요지, 검색어와 검색일)

### 4-6. ⑥ EU 노출 (신설)

- CBAM은 EU 제도이므로 미국·아시아 수출은 수요를 만들지 않음. 해외 비중이 아니라 EU 노출로 채점함
- cbam_eu_exposure(확인/신규/축소/불명/미확인), exposure_type(직수출/전구물질/역내생산/해당없음), eu_item_match(일치/불일치/불명/해당없음) 세 칸으로 판정함
- eu_item_match는 EU 매출이 확인된 계정에만 적용함. "이 회사가 CBAM 품목을 만드는가"와 "EU로 나가는 것이 그 품목인가"는 다름
- 확인 방법: 사업보고서의 제품별 매출 표와 지역별 매출 표를 대조함. 둘 다 있으면 일치/불일치, 하나라도 없으면 불명
- 해외 비중은 점수에서 빼고 순위표 참고 칸으로만 둠 (data/manual/mfg2_overseas.csv)
- 기록: data/manual/cbam_eu_exposure.csv

### 4-7. 은행 차입 표시 (점수 아님)

- 대상: 합계 **7점 이상 35곳** (점수 구간에서 끊음. 상위 30곳으로 자르면 7점 구간 한가운데가 갈림)
- 차입처: DART 원문의 차입금 주석을 코드로 뽑아(bank_scan) 이름을 집계함
- 금액: DART 재무제표 API(fnlttSinglAcntAll)에서 재무상태표의 차입·사채 계정을 원 단위로 받음
  - 별도(OFS)와 연결(CFS)을 모두 보고 차입금 계정을 실제로 찾은 쪽을 씀
  - 양쪽 모두 계정이 없거나 금액이 0이면 무차입으로 확정함
  - API에 자료가 없거나 0인 계정은 원문 주석 판독값(MANUAL_AMT)을 씀
- 기록: data/manual/mfg_bank_borrowing.csv
