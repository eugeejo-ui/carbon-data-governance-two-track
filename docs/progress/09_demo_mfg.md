## 4. 세부 내용 (09-1: 4-1~4-4 · 09-2: 4-5 · 09-3: 4-6)

### 4-1. 앵커 연도 [확정]

**① 이미 정해진 것 (08 4-2)**

- 앵커는 회사별 연간 공개 실측값이며, 합성값의 합계는 앵커와 일치해야 함
- 앵커 4종: 사업보고서 생산실적, 등록공장, 온실가스 명세서 총량(배출량·에너지 사용량), EU CBAM 규정
- 앵커 연도는 명세서가 공개된 최신 연도 하나로 통일하고 사업보고서도 같은 연도를 씀

**② 기준 설명**

- 배출량과 생산량의 연도가 다르면 두 숫자가 맞지 않음
- 명세서와 사업보고서의 최신 연도가 다를 수 있으므로 명세서 연도에 맞춤
- 4-2 판정 기준 ①(감사의견)도 이 연도의 재무제표를 봄

**③ 원문 확인 — 명세서**

- 자료: 온실가스 에너지 목표관리 명세서 주요정보 (온실가스종합정보센터 공개 자료, 2026-10-08 내려받음)

### 4-6. 09-3 원재료(전구물질) 배출량 출처 조사

**① 이미 정해진 것 (08 4-2, I-02 4-2)**

- CBAM 내재 배출량에는 사들인 원재료(전구물질)의 생산 배출이 포함되나 명세서 총량에는 포함되지 않음 → 앵커 밖 항목으로 추가함. 앵커는 바꾸지 않음
- 1순위 납품사 공개 원단위("참고값(회사 평균)" 표시) / 2순위 EU 기본값 중 원산지 국가의 값 / 임의 가정값은 쓰지 않음 (2026-10-09 명확화, 08 반영은 C-005 예정)

- 08 4-4 추가 장면 4: EU 기본값과 납품사 공개값을 나란히 남기고 선택 근거를 기록함
