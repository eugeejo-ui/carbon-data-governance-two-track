- 작업 방식·조사 원칙은 CLAUDE.md 한 곳에 둠. CLAUDE.md는 공개 레포에 올리지 않고(.gitignore), 사용자 PC 레포 폴더(클로드 코드가 자동으로 읽음)와 claude.ai 프로젝트 문서(대화가 읽음) 두 곳에 같은 내용으로 둠. 고칠 때는 두 곳을 함께 고침. 각 대화는 시작 프롬프트에서 CLAUDE.md와 이 문서를 먼저 읽음

  - 자료 등급: 공시 원문(DART·KIND) → 정부·감독기관 → 신용평가사 → 회사 공식 → 주요 언론·글로벌 IB. 위키백과·나무위키·취업 정보 사이트·블로그는 사용하지 않음

  - 접속 시험: 대화 시작 시 필요한 외부 사이트 접속 여부를 먼저 확인함
  - 문서 문체: 개조식 어미, 한자어 서술형, 판정은 채택·부분 채택·기각
