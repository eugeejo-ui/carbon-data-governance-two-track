### 4-7. H4 판정 세부 기준 [확정] (시험 전 고정, 2026-10-07)

- 근거 기준: 계획서 6-2·07 문서 4-1 — 채택(주요 구간 자동 추적 확인) / 부분 채택(SQL·ETL 구간만 추적, 결론에 추적 가능 범위 조건을 붙임) / 기각(주요 구간 추적 불가, 주장을 카탈로그·품질로 축소)
- 아래는 이 기준을 시연 결과에 적용하는 방법이며, 기준 자체를 바꾸지 않음
- 판정 대상은 wdi임. 보조 제품의 결과는 판정에 넣지 않음

**주요 구간 정의**

- 계획서 6-1의 H4 문장("두 트랙의 데이터 흐름(원천 → 계산 → 공시)을 추적할 수 있음")의 세 구간을 주요 구간으로 정함

| 구간 | 내용 |
|---|---|

| ② 계산 | SQL·Python 또는 처리 도구로 배출량·품질 점수를 계산하는 구간 |
| ③ 결과 전달 | 제조 결과를 은행 장부·공시용 표로 넘기는 구간 |

**구간 상태 기록**

| 상태 | 뜻 |
|---|---|
| 자동 | wdi가 스스로 계보를 그림 |
| 보완 시 가능 | 주석·OpenLineage·사용자 정의 매핑(00 문서 5-2)으로 이어짐. 보완 방법과 작업량을 함께 기록함 |
| 불가 | 보완해도 이어지지 않음 |

**결과별 판정**

| 결과 | 판정 | 결론에 붙는 조건 |
|---|---|---|
| 세 구간 모두 자동 | 채택 | 없음 |
| 일부 구간이 "보완 시 가능" | 부분 채택 | 구간별 보완 방법·작업량 |
| 일부 구간이 "불가"이고 다른 구간은 자동 | 부분 채택 | 추적 가능 범위 제한 |

## 9. 한계

- 합성 데이터이며 실제 고객 사내 데이터에 적용한 검증이 아님 — H4 재판정은 "실제 형태의 데이터 적용"까지로 한정됨
- 체험판 환경(원천 3개·30일)이며 운영 규모의 성능은 확인하지 않음
- 장부는 각 은행의 제조 94곳 거래만 담으며, 은행 전체 제조업 노출의 일부임
- 알려진 누락 2건이 장부 숫자에 반영되지 않음
- 납품사 공개 원단위는 회사 평균이며 CBAM 실제값으로 인정되지 않음
- 보정 자료 5종과 체험판 조건의 이용 가능 여부는 미확인 상태임 (접속 점검 결과는 2-5)
- 보조 제품은 판정 대상이 아니며, 보조 제품의 체험 기간·한도·지역 간 연결은 대부분 공식 페이지에 기재되지 않음 (11-1 확인)
- Envizi 계산값은 계수 출처와 산정 범위(공정 배출 제외)가 명세서와 달라 참고값으로만 사용함
- 일부 공식 페이지(IBM 요금제 문서 등)는 본문이 자동으로 읽히지 않아 사용자 발췌가 필요할 수 있음
- 시연 대상 중 삼아알미늄은 06 영업 로드맵에 없음(02 채점 7점) — 알루미늄 자리에서는 시연 대상과 영업 연락 대상이 직접 이어지지 않음. 06 규칙을 적용하면 2026 하반기(EU 확인)에 해당함(참고)
- 판정 기준 ⑥·R1·순서 기준은 09-1 진행 중에 만든 기준이며, 그중 ⑥은 사후 기준임
- 09-1 원문은 사용자 첨부에 의존함(대화 ①에서 DART·KIND·온실가스종합정보센터 자동 접속 차단). 대호에이엘 상장폐지 결정(2026-08-04)은 보도로만 확인함
- R1 여유가 작은 2곳(삼아알미늄 55.37%, 한일시멘트 52.47%)과 태웅 품목번호 가정(단조 상태 7326)이 있음
- 현대비앤지스틸의 자체 탄소 관리(SCEMS 등) 여부는 공개 자료 범위에서 미확인임 — 확인되어도 순위는 유지되나 영업상 빈자리가 작아질 수 있음
- Envizi 비교가 성립한 2곳의 전력 사용량은 TJ로만 공개되어 kWh 환산 기준이 미확인임
