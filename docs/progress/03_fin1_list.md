### 2-0. 공통 원칙

| 원칙 | 내용 | 이유 |
|---|---|---|
| 코드로 판정 | 업권은 이름이 아니라 DART 표준산업분류(KSIC 10차) 코드로 정함 | 사명에 업권이 안 드러나는 곳(카카오뱅크·한국금융지주)을 놓치지 않기 위함 |
| DART 우선 | 손보정은 인가 업권과 다른 것이 확인된 경우만 함 (다올투자증권 661 → 증권, 1건) | 기억으로 만든 분류표가 틀렸던 사례가 있음 (10장 오류 1) |
| 근거 자료 순위 | 공시 원문(DART·KIND) > 정부·감독기관(금감원 FISIS 포함) > 신용평가사 > 회사 공식 > 주요 언론·글로벌 IB | 위키백과·나무위키·취업정보 사이트·블로그는 누구나 고칠 수 있어 근거로 쓰지 않음. 현대카드 지분을 위키백과로 적었다가 신용평가사 합계(78.1%)와 맞지 않아 폐기한 사례가 있음 |
| 기준선 | 반올림 없이 원 단위로 끊음 | 한국토지신탁 1.9909조를 2조로 올리면 "왜 1.83조는 안 되나"가 됨 |
| 기준표 한 곳 | 업권표·제외 규칙·지분 문턱·음역표는 src/fin/fin1_list.py에만 두고 나머지 파일이 가져다 씀 | 파일마다 표가 달라 같은 코드가 다른 업권으로 나온 사례가 있음 (오류 4). 음역표도 두 파일에 흩어져 있다가 통합함 (오류 12) |
| 계산 방법 명시 | 산출한 모든 수치에 "어느 자료 몇 쪽의 어느 숫자를 어떻게 계산했는지"를 원 단위로 적음. 추정치는 추정 근거·계산식·한계까지 적음 | 누가 원문을 열어도 같은 숫자를 다시 만들 수 있어야 함 (2026-10-01 사용자 지시) |
| 교차 확인 | 서로 다른 1차 자료가 있으면 대조함 | IBK 3사 자산이 기업은행 감사보고서와 FISIS에서 백만원 단위까지 일치 / 국민은행 FISIS 584.93조 = DART 584.93조 / 신보 보증잔액 77.7조 = 보도 |
| 코드 전달 | 가상 실행 결과를 먼저 보고하고 승인 뒤 전달함. 찾기 문자열이 사용자 파일에 1회 있는지 확인함 | 들여쓰기·잘못된 API·없는 문자열 교체 지시 등이 반복됨 (10장) |
| 새 API는 실제 응답부터 | 명세에 예시가 없는 응답 형식은 추측하지 않고 실제 응답 한 건의 구조를 먼저 확인함 | FISIS JSON 구조를 XML 예시로 추측했다가 실행 오류 (오류 11) |
| 긴 코드는 파일로 | 수백 줄 코드는 내려받을 파일로도 주고 줄 수로 확인함 | 붙여 넣다 마지막 줄이 끊겨 문법 오류 (오류 14) |
| 5등급은 지정 매체만 | 5등급은 조선·중앙·동아·한경·매경과 글로벌 IB 리서치만. 경제 전문지·인터넷 매체(딜사이트·더벨·비즈한국·뉴데일리 등)는 "등급 외(참고)"로 두고 상위 등급으로 대체함. 옛 자료는 날짜를 함께 적음 (2026-10-01) | 1-3C 1차 조사에서 전문지를 5등급으로 매기고 2019~2022년 지분을 현재값처럼 씀 — 사용자 점검으로 발견 (오류 17) |
| 실제 원문으로 시험 | 원문을 읽는 코드는 가짜 자료가 아니라 실제로 받은 원문으로 시험함 | 감사보고서 주주 표 형식이 회사마다 달라 가짜 자료로는 못 잡음 (오류 20) |

### 2-1. 대상을 비상장 비종속까지 넓힐까

- **핵심 질문**: 계획서 v1.5는 비상장 비종속(교보생명·농협·산업은행 등)을 "자료를 구하기 어렵다"며 뺐음. 이 전제가 맞는가?

| 선택지 | 내용 | 평가 |
|---|---|---|
| 뺌 (v1.5) | 상장사와 그 종속만 | 비상장도 DART에 감사보고서를 내므로 전제가 틀림 |
| **넣음** | 비상장 비종속도 포함 | 제조2-6에서 대상 35곳 중 32곳(91%)이 산업·수출입·기업은행과 거래함. 두 국책은행은 제조 계정의 최대 채권자이면서 금융배출량을 산정하지 않음 |

- **결정**: 넣음. 국책은행은 전부 명단에 넣되 제조 트랙에서 언급된 은행을 집중 분석하고, 언급이 없어도 점수가 높으면 신규 고객으로 선정함 (2026-09-30)

### 2-2. 공공금융기관의 ① 공시 지위는 몇 점인가

- **핵심 질문**: ①은 "공시 때문에 급한가"를 잼. 산업은행·수출입은행은 자본시장법 공시 대상(주권상장법인)이 아닌데 급하지 않은가?

| 선택지 | 점수 | 판단 |
|---|---|---|
| A | 0점 — 공시 의무 없음 | **틀림.** 자본시장법만 본 것. 두 은행은 기타공공기관이라 알리오 통합공시 의무가 있고, 온실가스 공시가 Scope 3(금융배출 포함)까지 단계적으로 넓어짐 |
| **B** | **1점** — 의무는 있으나 처벌이 약함 | 알리오 위반은 경영평가 감점. 비상장 종속회사와 같은 칸 |
| C | 2점 — 상장사와 동급 | 과함. 자본시장법 허위기재는 손해배상·형사처벌 |

- **결정**: B. 대신 ②(현재 빈칸)에서 미산정이라 2점을 받아 합계에서 불리하지 않음. "의무는 있는데 아직 못 하고 있다"가 ①1점 + ②2점으로 드러남
- 기업은행(중소기업은행)은 코스피 상장사이면서 기타공공기관(정부 지분 59.50%, 알리오 등록)임. 상장사 기준(2점)이 더 높아 상장 층으로 둠
- **강화 요인(점수 미반영)**: ESG 기본법 초안(발의 전)이 공공금융기관에 금융배출량 산정 의무를 직접 부과함 → 계획서 5-2 재확인 항목

### 2-3. ESG 공시 의무는 코스피에만 걸리는가

- **결정**: 코스피 한정은 유지하되, 종속회사는 "지배회사 연결 공시"를 근거로 ① 1점

### 2-7. 여신·투자 포트폴리오가 없으면 뺄까

- **핵심 질문**: 금융배출량은 "돈 대준 회사의 탄소"인데, 대출이 없는 곳은 빼야 하나?

| 선택지 | 판단 |
|---|---|
| 여신 없으면 제외 (처음 제안) | **철회.** PCAF는 셋으로 나뉨 — Part A 금융배출량(대출·투자), Part B 촉진배출량(증권 인수·주선), Part C 보험배출량(보험 인수). 증권·보험은 여신이 없어도 산정 대상. 카카오페이도 증권·손보 자회사가 있어 해당 |
| **인수·여신·투자가 모두 없는 곳만 제외** | 자회사형 GA(보험을 파는 곳이지 인수하지 않음), 손해사정, 고객센터·IT, 대부업(계열사 자금 운용) |

- **결정**: 후자. GA는 1차 자료로 확인함 — 마이금융파트너(현대해상 2021-02 출범, 사업목적 보험대리점업)·삼성생명금융서비스(2015년 삼성생명 400억 출자)·한화생명금융서비스(2021-04 제판분리)·한화라이프랩(한화생명 100% 출자)·케이피보험서비스(카카오페이 계열)

### 2-8. 종속은 어떻게 판정하나

|---|---|
| 보통주 지분 50% 초과 | 경영을 좌우하려면 투표권 과반이 필요 |

| 지분율의 `%`·공백은 떼고 읽음 (2026-10-01) | "100.00%"처럼 적힌 값이 0으로 읽혀 조용히 빠지지 않게 |

|---|---|---|---|
| ③-1 제조업 노출 | 보유액 × 제조업 비중 | 감사보고서 산업별 익스포저·업종별 보증잔액 | 업권 추정 + "추정" 표시 |

- ③-3은 두 트랙을 잇는 고리 자체임. 제조 94곳 전체의 차입금 주석에서 차입처별 금액까지 집계함 (금융-2 첫 작업)

## 11. 한계

- 종속회사는 지배회사가 직접 출자한 1단계만 봄. 2조 이상 금융 손자회사는 FISIS 명단이 안전망이 되나(메리츠캐피탈), 2조 미만 손자회사(한화피플라이프·IFC그룹 등)는 안 잡힘
- 이름으로 업권을 정한 계정이 남아 있음 (1-2 5곳·1-2b 18곳). DART에 같은 음역 이름이 여럿이거나 등록되지 않은 곳
- 원문 수동 입력은 사람이 옮겨 적은 값이라 감사보고서가 새로 나오면 다시 확인해야 함 (확인일·출처 쪽수 기록)
- 실질 지배는 지분 30~50%·자산 1조 이상만 검토함. 1조 미만 관계기업 중 실질 지배가 있는 곳은 놓칠 수 있음
- 현대카드 연결 종속 여부는 FY2023 사업보고서·FY2024 연결감사보고서로 확인했고 FY2025 원문은 미확인
- DB저축은행은 대주주 적격성 소송 결과에 따라 모회사가 바뀔 수 있음
- 자산 기준이 층마다 다름 — 상장 층 DART 연결, 1-3A 공정위(별도로 보임), 1-3B 감사보고서(은행 연결·기금 국가회계기준), 1-3C FISIS(은행·지주 연결, 나머지 별도)
- 1-3C는 FISIS 업무보고서 기반(국가승인통계 아님, 금감원 명시). FISIS에 법인등록번호가 없어 DART 이름 대조를 거침 — 이름이 완전히 다르게 등록된 곳은 새 후보로 잘못 뜰 수 있어 한 곳씩 검토함
- 1-3C에서 외은지점·외국 증권사 서울지점·상호금융 단위조합을 뺌 — 제조 35곳 차입처인 HSBC·미즈호 등은 참고 목록에만 있음
- 1-3C 소유 구조는 2025년 말 감사보고서·사업보고서 기준. 이후 변동은 공시·보도로 "변동 예정"에 적었으며 매각 8곳은 결과에 따라 층이 바뀜. 한국SG증권은 원문에 지분율 숫자가 없음. 수협은행·예별손보는 DART에 감사보고서 공시가 없어 3·2등급 자료로 확인함
- 감사보고서 주주 읽기는 실제 원문 16건의 표현 형식으로 맞춘 것이라, 새로운 서술 형식이 나오면 못 읽을 수 있음 (못 읽으면 "1등급으로 확인 못 한 곳"에 문장과 함께 표시됨)
- 예별손보는 존속기간 2년 조건부 가교보험사 — 매각이 안 되면 계약이 5대 손보사로 이전되고 정리됨
- 무보 제조업 비중은 추정(77.82%, 하한) — 비제조 사업 미차감, 중장기 잔액 비중 미반영
- 신보·기보·무보는 PCAF에 보증·신용보험 산정법이 없음 (계산법 미정)
- 중소벤처기업진흥공단은 제조 트랙과 차주가 겹치지 않아 제외함
- 솔루엠코스메틱(0.05조)은 DART 코드가 649(기타 금융)라 코드 판정으로 들어왔으나 이름은 화장품 — 금융-2에서 실제 업무 확인
- 핀크(하나금융 핀테크 앱)는 포트폴리오가 없어 보이나 처리 미확정 (신용정보사는 2-24로 정리)
- 연결자산총액은 2025 사업연도 기준. 종속회사 현황은 사업보고서 기준이라 기중 변동이 반영되지 않음
